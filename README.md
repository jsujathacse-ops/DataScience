# Data Science Lab Experiment 01

## Experiment Title

Exploring Kaggle & GitHub

## Objective

To create Kaggle and GitHub accounts, download a dataset from Kaggle, perform basic Exploratory Data Analysis (EDA), and upload the project to GitHub.

## Dataset

Titanic Dataset

Source:
https://www.kaggle.com/

## Software Used

- Python
- Pandas
- Jupyter Notebook
- GitHub

## Files Included

- train.csv
- analysis.ipynb

## Exploratory Data Analysis Performed

- Loaded the dataset using Pandas
- Displayed the first five rows using head()
- Checked dataset information using info()
- Generated summary statistics using describe()
- Identified missing values using isnull().sum()

## Conclusion

The Titanic dataset was successfully analyzed using basic EDA techniques and uploaded to GitHub.
